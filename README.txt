DAILY MONEY TRACKER - how to put it on a phone

1. Unzip this folder.
2. Go to https://app.netlify.com/drop and drag the whole folder onto the page.
   (If you already have a site, open it > Deploys tab > drag the folder there to update it.) You get a link like https://something.netlify.app
3. Send that link to your friends.
4. On their phone:
   - iPhone (Safari): Share button > Add to Home Screen
   - Android (Chrome): menu (three dots) > Install app / Add to Home screen
   The Daily Money icon appears on the home screen and opens full screen, even offline.

Each person's data stays on their own phone. It does not sync between devices.
